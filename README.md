# SignCourse Studio · 手语课程编排工具

SignCourse Studio 是面向手语教师的课程设计工作台。教师可以把示范片段、手形说明、字幕、镜头角度、常见错误和练习任务组合为学习步骤，并在手机和平板预览中检查字幕安全区、步骤依赖和替代文本。

## 功能

- 课程模块：创建多个模块，维护模块目标、主题色和学习步骤。
- 步骤编排：每个步骤支持示范、讲解、练习类型，以及时长和入门/进阶/挑战难度标签。
- 动作素材：记录示范片段名称、可选的本地素材地址、手形说明、主要动作区域和镜头角度。
- 字幕与无障碍：设置字幕文本、字幕位置和替代文本，并在预览中标记字幕与动作区域冲突。
- 学习依赖：选择前置步骤，检查前置项不存在或指向后续步骤的跳级问题。
- 练习设计：记录练习任务、反馈方式和常见错误清单。
- 设备预览：在手机 9:16 和平板 4:3 视图间切换，并运行带检查点的动作时间线。
- 发布前检查：检查字幕遮挡、步骤跳级、替代文本缺失、练习反馈不完整和常见错误缺失。
- 状态流转：支持草稿、提交复核、退回修改、冻结版本和基于冻结版本创建修订版。
- 离线副本与三方合并：两位老师可基于同一冻结版本各自导出离线副本（JSON），离线编辑后交回；合并中心以冻结版本为共同祖先做三路合并——
  - 先按冻结版本分别列出甲、乙各自改了什么；
  - 同一步骤不同字段的改动自动并入，双方一致的新增自动收敛；
  - 同一字段两边都改成不同值时保留甲、乙两版，由老师逐项二选一；
  - 一边删除步骤/模块、另一边仍在修改时默认保留并生成「删除 vs 修改」冲突，绝不直接丢；
  - 模块与步骤顺序按稳定 id 做 diff3 对齐：单边换位/插入自动采用，同位置双方排法不同才产生顺序冲突，可选甲序、乙序或两边都保留；
  - 合并会话、冻结版本、两份副本和全部裁决记录都保存在 `localStorage`，未完成可中断，重开页面在「会话记录」中继续；完成后结果作为新草稿装入编辑器。
- 离线编辑：所有修改保存在 `localStorage`；浏览器离线或刷新后可继续编辑。
- 键盘操作：`⌘/Ctrl + Z` 撤销、`⇧⌘/Ctrl + Z` 重做、`⌘/Ctrl + S` 保存草稿、`Alt + ↑/↓` 调整步骤顺序。

## 技术栈

- Stencil 4
- TypeScript 5
- Ionic 9
- Ionic Core CSS

## 开发

```bash
npm install
npm run dev
```

Stencil 开发服务器默认监听 `3333` 端口，并启用监听构建。

## 构建

```bash
npm run build
```

生产静态文件输出到 `www/`。构建会同时生成 Stencil 分发包和组件文档。

## Docker

```bash
docker build -t sologsb-1012 .
docker run --rm -p 10012:80 sologsb-1012
```

容器内部由 nginx 监听 `80`；宿主端口按根项目端口表映射为 `10012`。
